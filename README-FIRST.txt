ACG Radar 1.0.0 - 快速开始

1. 安装 Python 3.10 或更新版本：
   https://www.python.org/downloads/
   安装时勾选 "Add Python to PATH"。

2. 把整个压缩包解压到一个可写目录，例如：
   D:\ACG-Radar

3. 双击 start.bat
   浏览器会自动打开 http://127.0.0.1:8765

4. 第一次使用：
   - 在“设置”中配置 AI API（Base URL、模型、Key）
   - 如需 R18，配置 Bangumi Access Token 和 Cookie
   - 点“检查连接”确认三项状态
   - 在“添加作品”中搜索并导入作品

数据保存位置：
   data\app.db
   data\secrets.json

不要直接双击 app.py。请使用 start.bat。
停止程序：关闭命令行窗口，或按 Ctrl+C。
